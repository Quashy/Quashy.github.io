# 从零开始的金融生活

![小黑掀开一张巨大的投资凭证，看到背后饭店、交易和登记交收的分工](/finance-from-scratch/03.png)

> 股票、债券、基金这些词平时经常能听到，再往下看，又会遇到交易所、券商、中债登、中证登这些名字。它们各自负责什么，买一只股票或者债券的时候，钱和资产又是怎样流转的？

## 0x00 起因

最近在一家公募基金公司实习，来之前也幻想着金融行业非常高大上。对于金融一窍不通的我来说，固收、权益、债券、分销这些名词和概念都很新鲜，也觉得挺有意思的。

带着这份好奇，我也想了解不同金融机构在市场这条链条里各自处在什么位置、发挥什么作用，所以浅浅学习了一下，顺便把这些基础概念梳理下来。

## 0x01 市场：一笔交易需要哪些机构配合

- **交易所市场**：交易在上交所 / 深交所，结算在中证登。
- **银行间市场**：交易在 CFETS，结算托管在中债登、上清所。

| 项目           | 银行间市场                               | 交易所市场                       |
| -------------- | ---------------------------------------- | -------------------------------- |
| 定位           | 债券大宗批发市场                         | 债券零售市场                     |
| 参与人         | 只有机构，个人不能直接进                 | 机构 + 散户（满足权限）          |
| 交易方式       | 询价、一对一谈价                         | 竞价撮合，盘口自动成交           |
| 主流品种       | 同业存单、国开债、大部分地方债、短融中票 | 可转债、交易所国债、公司债       |
| 单笔门槛       | 极高，千万级别常见                       | 低，可转债 1000 起               |
| 托管机构       | 中债登、上清所                           | 中证登                           |
| 普通人参与方式 | 买债券基金、同业存单基金                 | 证券账户直接买（可转债、国债等） |
| 市场规模       | 占债券市场 90%+，绝对主力                | 体量小很多                       |

![银行间市场的机构与交易所市场的机构、个人分别进入两扇门，个人持证券账户参与交易](/finance-from-scratch/11.png)

**金融基础设施**提供市场运行所需的公共机制和系统。

- **交易类**：上交所、深交所、CFETS，主要提供交易组织、成交及相关服务。
- **登记结算类**：中国结算、中债登、上清所，主要提供证券登记、存管、清算结算等服务。

**金融机构**依托这些基础设施，作为市场参与者和金融服务提供者。替客户办理金融业务，或直接参与融资与投资。

- **中介机构（券商、银行、基金公司）**：持牌的「接入代理商」。
  - **券商**：证监会牌照，主打交易所经纪、自营、代销；
  - **银行**：很多是 CFETS 核心会员，银行柜台卖国债，是银行自己在 CFETS 批发买来再拆零售；
  - **基金公司**：持牌机构，自己申请 CFETS 会员，下场买债。

::: details 举个例子🌰：

假设你通过证券账户买入一只已经上市的股票，你先把买入委托交给券商，再由券商接入交易所的系统。

交易所负责组织成交，成交后的证券登记结算则由中国结算等参与完成。

:::

顺着这笔交易看，券商提供**接入服务**，交易所**组织买卖**，登记结算机构负责后续的**登记和交收**，就比较容易分清它们各自的位置了。

![小黑接收买入委托、匹配买卖单，再核对钱与股票的交收，展示券商、交易所和登记结算的分工](/finance-from-scratch/04.png)

## 0x02 投资资产：买的是股权，还是债权

> 先看投资者的身份：**买股票成为股东**，**买债券成为债权人**。

虽然都是把钱投出去，但持有的权利不同，后面关注的收益和风险也就不同。

| 比较角度     | 权益，以普通股票为例                 | 固收，以普通债券为例             |
| ------------ | ------------------------------------ | -------------------------------- |
| 投资者身份   | 股东                                 | 债权人                           |
| 核心权利     | 分享公司剩余收益                     | 按约定收取利息、本金             |
| 收益来源     | 分红、股价变化                       | 利息、债券价格变化               |
| 主要研究问题 | 公司未来能赚多少，市场愿意给多少估值 | 能否偿付，利率和信用风险如何变化 |
| 期限         | 普通股票通常没有到期还本安排         | 普通债券通常有约定到期日         |
| 清偿顺序     | 通常在债权人之后                     | 通常优先于普通股股东             |

![两个小黑面对同一家饭店，一个拿到公司的一小块股权，另一个拿到写明本息约定的债券](/finance-from-scratch/05.png)

### 2.1 权益：成为公司的股东

**本质**：买公司所有权，买的是公司的一部分，典型的就是**股票、指数**。

- **收益来源**：持有期间的分红 + 股票价格的变化。
- **主动权益**：基金经理**主动选股**、配置仓位，争取取得超越业绩基准的表现。
- **被动权益**：主要按照某个**股票指数**构建组合，争取让基金表现贴近该指数。

![一只小黑主动挑选股票卡片，另一只按照指数样板摆放股票卡片，说明主动与被动权益的区别](/finance-from-scratch/06.png)

如果把它放到一家饭店连锁公司里理解，买了公司的股票，就持有了**这家公司的一部分**。

公司经营得怎么样、未来还能开多少店，都会影响投资者对它的判断；持有期间可能收到分红，卖出时的价格也可能比买入时高或者低。

下面这张图把股票从发行到持有的过程串了起来。 **IPO** 是首次公开发行，网上、网下对应不同的申购渠道；基金等投资者由基金经理作出投资决策，再由交易员执行。

![权益泳道图：发行人、券商、投资者、交易所与登记结算机构在股票发行和买卖中的分工](/finance-from-scratch/01.png)

可以顺着一家准备上市的饭店连锁公司走一遍：

公司希望**募集资金开新店**，券商帮助它组织发行和承销，投资者研究后参与申购。

确定认购结果并缴款，完成相应的登记交收后，**公司取得募集资金，投资者取得股票**。

等股票上市以后，假设投资者甲想卖，投资者乙想买，他们通过券商提交委托，在交易所成交后再完成清算交收，股票就由甲转到了乙手里。

> **这时乙支付的买入款是给卖方甲的，公司不会因为每一次股票买卖都再收到一笔钱。**
>
> 这也是图里「发行交收」和「二级买卖」分成两段的原因。

![发行时投资者把钱交给公司，二级买卖时新买方把钱交给原持有人，公司不重复收取买入款](/finance-from-scratch/07.png)

后面乙继续持有股票，如果公司决定分红，就按相应安排取得分红；如果乙选择卖出，则由下一位买方接着持有。

对照图中的几条泳道，公司的融资、投资者的买卖以及基础设施提供的服务就能连起来了。

### 2.2 固收：成为发行人的债权人

**本质**：固定收益，**债券**是最典型的固收资产。

**收益来源**：利息收入 + 债券价格变化。

还是拿这家饭店连锁公司举例，如果它通过发行债券来筹钱，买入债券的投资者就是债权人，按债券约定**收取利息和本金**。

其中不止需要关心公司经营得怎么样，还要看它能否**按约定把钱还上**。

![固收泳道图：发行人、承销机构、投资者、交易平台与登记结算机构在债券发行、持有和兑付中的分工](/finance-from-scratch/02.png)

假设公司发行一只期限为 **3 年、每年付息一次**的普通债券，投资者参与认购并缴款后，公司取得募集资金，投资者开始持有债券。

持有期间**按条款收息**，如果一直**持有到期**，就按约定取得到期兑付款。

如果投资者在**第 2 年需要用钱**，也可以考虑把债券卖给其他投资者。

买卖通过对应市场的交易平台进行，再由相应登记结算机构办理交收；**卖方退出这笔持仓，买方接着持有**，并取得后续条款约定的本息。

> 这时卖出能拿回多少钱，还要看**当时的债券价格**，所以前面的收益来源里也有「债券价格变化」。

![旧持有人把债券卖给新持有人并收到卖出款，新持有人接续取得后续约定本息](/finance-from-scratch/08.png)

## 0x03 公司架构：股东、董事会和管理层各做什么

前面说买股票成为股东，接下来就可以看看公司内部是怎样分工的。持有公司的一部分，与负责公司的日常经营，是两件不同的事。

把公司分成三层：

> **股东会选董事 → 董事会定方向、监督管理层 → 管理层负责日常经营。**

| 简称          | 中文       | 主要负责什么                                 |
| ------------- | ---------- | -------------------------------------------- |
| **CEO** | 首席执行官 | 全面负责公司经营，协调各业务，对经营结果负责 |
| **CTO** | 首席技术官 | 技术方向、技术架构、研发能力等               |
| **CFO** | 首席财务官 | 财务管理、预算、融资、资金安排等             |
| **COO** | 首席运营官 | 日常运营、业务流程和执行效率等               |

拿饭店连锁公司举例：

- **董事会**：决定未来重点发展哪个市场，批准重要投资。
- **CEO**：带领整个团队，把发展计划做成生意。
- **CTO**：负责点餐系统、配送平台等技术能力。
- **CFO**：算清开店预算、资金够不够、是否需要融资。
- **COO**：确保各家门店人员、采购和服务运转顺畅。

![小黑股东投票选出董事，董事会确定开店方向，管理层把计划落实为饭店日常经营](/finance-from-scratch/10.png)

## 0x04 投资决策：为什么买这笔投资

还是拿前面的饭店连锁公司举例，看看投资者会根据什么作出买入判断。

### 4.1 基本面：研究公司，再看价格

饭店每天有多少客人，扣掉房租、人工和食材以后还能赚多少钱，新开的门店能不能复制原来的经营效果，这些都属于**基本面分析**会研究的问题。

根据经营情况估计公司的价值，再与股价比较，就会用到**价值投资**的思路。比如估计每股值 **20 元**，现在市场上卖 **15 元**，认为存在低估，于是考虑买入。

**成长投资**更关注未来的业务和盈利增长，比如看好这家公司从一个城市开到全国，就会研究新店的盈利能力、扩张空间，以及当前股价已经反映了多少增长预期。

价值和成长可以同时成为买入理由，一家公司的成长潜力是可能被市场低估的。

### 4.2 技术面，以及其他买入理由

**技术分析**主要研究价格和成交量，常见工具包括 K 线、均线、MACD 等。例如观察股价突破某个区间时，成交量有没有增加，再按照相应规则安排交易。

![一只小黑掀开饭店屋顶研究经营，另一只用放大镜查看从同一家饭店展开的价格与成交量长卷](/finance-from-scratch/12.png)

除了价值和成长，还可以从这些角度形成判断：

| 投资思路                       | 放到饭店公司里怎么理解                                     |
| ------------------------------ | ---------------------------------------------------------- |
| **收入／红利投资**       | 研究公司的盈利、现金流和分红，希望持有期间持续取得现金收入 |
| **宏观／行业／主题投资** | 从居民消费、旅游需求、政策等变化入手，研究哪些公司会受益   |
| **趋势／动量交易**       | 判断已经形成的价格趋势是否会延续                           |
| **逆向／均值回归**       | 判断市场是否反应过度，寻找价格或情绪回归的机会             |
| **事件驱动**             | 研究并购、分拆、重组等具体事件会怎样改变公司价值           |

基本面和技术分析也可以结合使用，比如先研究公司的经营情况，再参考价格走势安排买卖。

### 4.3 量化、指数投资和定投

**量化投资**会把判断写成规则或模型，用数据进行筛选和执行。比如按照估值、盈利能力筛选公司，或者根据价格趋势设定买卖条件，都可以采用量化方式。

**指数投资**和前面说的被动权益接上了，基金按照指数规则构建组合，争取贴近指数表现。投资者主要选择参与哪个市场、哪类公司，比较相应基金的费用和跟踪情况。

**定投**是在固定时间投入固定金额，比如每月买入一定金额的指数基金。这里，指数投资决定参与什么，定投安排资金怎样持续投入。

![小黑站在日历前用固定大小的量勺投入资金，篮子中的多家公司卡片代表指数基金的投资组合](/finance-from-scratch/13.png)

### 4.4 买入以后看什么

买入的理由，也决定了持有期间需要跟踪的信息。

看好饭店继续扩张，就关注新店数量、单店盈利和投入回收情况；

为了取得分红，就研究经营现金流和利润分配；

按照趋势交易，就检查价格是否仍然符合交易时定下的套利策略或规则。
